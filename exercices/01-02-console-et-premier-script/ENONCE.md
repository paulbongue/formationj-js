
# Exercice 01-02

Ouvre `exercice.mjs` et complète les deux fonctions.

## 1. `presentation(prenom, langage)`

Renvoie une phrase exactement au format :

```
Je suis Black et j'apprends JavaScript.
```

## 2. `doubler(n)`

Renvoie le double du nombre reçu.

## Attention

Ces deux fonctions doivent **renvoyer** (`return`) une valeur, pas l'afficher.

## Corriger

```
js 01-02
```
