
# Exercice 02-08

## 1. `fizzbuzz(n)`

Renvoie un **tableau** de 1 à `n` où : les multiples de 3 deviennent `"Fizz"`, ceux de 5 `"Buzz"`, ceux de 15 `"FizzBuzz"`. Les autres restent des **nombres**.

```js
fizzbuzz(5)   // [1, 2, "Fizz", 4, "Buzz"]
```

## 2. `sommePairs(n)`

Somme des nombres pairs de 1 à `n` inclus. `sommePairs(10)` → `30`.

## 3. `tableMultiplication(n)`

Tableau de 10 chaînes : `"3 x 1 = 3"` … `"3 x 10 = 30"`.

## 4. `inverser(chaine)`

`"bonjour"` → `"ruojnob"`. Avec une boucle, sans `split().reverse().join()`.

## 5. `estPremier(n)`

`true` si `n` est premier. `1` et les nombres < 1 ne sont pas premiers. Arrête la boucle dès que possible — inutile de tester au-delà de la racine carrée.

## 6. `chercherPremierNegatif(nombres)`

Renvoie le **premier** nombre négatif du tableau, ou `null`. Utilise `break` : ne parcours pas la suite pour rien.

## 7. `pyramide(hauteur)`

Renvoie un tableau de chaînes formant une pyramide d'étoiles centrée.

```js
pyramide(3)
// ["  *  ",
//  " *** ",
//  "*****"]
```

Chaque ligne a la même longueur : `hauteur * 2 - 1`.
